## Tài Liệu Thiết Lập & Hướng Dẫn Chi Tiết
Vui lòng tham khảo file tài liệu đầy đủ tại: [PLAYWRIGHT_SETUP_GUIDE.md](file:///d:/testing_prj/PLAYWRIGHT_SETUP_GUIDE.md).

## Các Lệnh Chạy Nhanh

```bash
# Cài đặt thư viện
npm install

# Tải trình duyệt Playwright
npx playwright install chromium

# Chạy kiểm thử tự động
npm test

# Chạy kiểm thử với giao diện trực quan (UI mode)
npm run test:ui

# Xem báo cáo HTML
npm run test:report
```
